# Contributing

Contributions must preserve the architecture, terminology, and product goals defined in the source documents.

## Workflow

- Open a focused change with a clear goal.
- Update the relevant specification before implementation when behavior changes.
- Keep changes small, traceable, and reviewed.
- Add or update tests and docs together when needed.

## Expectations

- Do not introduce placeholder logic.
- Prefer clarity over cleverness.
- Respect the canonical platform vocabulary.
- Verify the result before considering the task complete.
