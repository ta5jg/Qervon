# Secure Development Lifecycle

## Purpose

This document defines secure development lifecycle for the Qervon platform.

## Guidance

- Shift security left into design and review.
- Require security checks before release.
- Keep secure coding standards visible to contributors.

## Common Security Baseline

- Use zero trust and least privilege.
- Keep authorization server-side and auditable.
- Protect sensitive data with clear handling rules.
