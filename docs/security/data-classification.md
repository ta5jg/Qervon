# Data Classification

## Purpose

This document defines data classification for the Qervon platform.

## Guidance

- Separate public, internal, confidential, and sensitive data.
- Treat tenant and personal data carefully.
- Make storage and handling requirements visible.

## Common Security Baseline

- Use zero trust and least privilege.
- Keep authorization server-side and auditable.
- Protect sensitive data with clear handling rules.
