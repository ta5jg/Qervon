# Threat Model

## Purpose

This document defines threat model for the Qervon platform.

## Guidance

- Identify assets, actors, trust boundaries, and abuse paths.
- Use structured analysis to reduce risk.
- Keep the model updated as the platform changes.

## Common Security Baseline

- Use zero trust and least privilege.
- Keep authorization server-side and auditable.
- Protect sensitive data with clear handling rules.
