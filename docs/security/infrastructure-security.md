# Infrastructure Security

## Purpose

This document defines infrastructure security for the Qervon platform.

## Guidance

- Harden hosts, networks, and runtime environments.
- Protect secrets and service identities.
- Keep infrastructure controls aligned with least privilege.

## Common Security Baseline

- Use zero trust and least privilege.
- Keep authorization server-side and auditable.
- Protect sensitive data with clear handling rules.
